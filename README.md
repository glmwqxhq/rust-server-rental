# Rust服务器租用：腐蚀开服该买什么配置，从计费方式到高防机型的选购与避坑清单

搜「Rust服务器租用」的人，目标通常很明确：想自己开一个腐蚀服，和几个人玩，或者做一个能对外拉人的社区服。真正难的地方不在付款那一步，而在下单之前——腐蚀是所有主流联机游戏里最吃服务器资源的一个，配置买低了不是"稍微卡"，而是开局十分钟就掉线、wipe 前直接崩。

下面这份内容按"先算需求、再挑机型、最后看价格"的顺序写。价格部分以雨云（RainYun）当前公开的产品线和方案为例，因为它的游戏云机型基本覆盖了腐蚀服需要的几个关键点：高主频 CPU、国内低延迟机房、DDoS 防御，以及按用量计费的弹性选项。

## 先算清楚：一台腐蚀服到底吃掉多少资源

腐蚀服务端和 Minecraft、CS2 完全不是一个量级。它模拟的是一个持续存在的大世界，里面有几万个建筑方块、几百个活跃实体、载具、动物和玩家背包数据，全部要实时计算。

具体到四个维度：

**内存是硬门槛。** 8GB 是能正常玩的下限，10–30 人的原版服建议 10–16GB，加 Oxide/uMod 插件之后往 16GB 起走，重插件或 150 人以上的大服要 32GB。麻烦的是内存会随 wipe 周期增长——开局占 6GB，一周后涨到 12GB 是常态，你买的其实是"周期末"的内存，不是"开服时"的内存。

**CPU 看单核，不看核心数。** 腐蚀服务端主线程压力集中在一个核心上，服务器 tick 靠单核性能顶。一台 4 核高主频的机器，实际体验会明显好过 32 核低频的云主机。这也是为什么游戏云普遍用 i9-14900K/14900KF、Ryzen 7950X/9950X 这类消费级高主频芯片，而不是数据中心里那些核心多、频率低的型号。第三方测评里，雨云 i9-14900K 机型在 Geekbench 6 上的单核成绩在 2800 分上下，这个水平应付 100 人级别的服是够的。

**硬盘要 NVMe，容量 30GB 起步。** 服务端文件本身 10–15GB，每个 wipe 的存档 1–5GB，插件和日志再吃掉 1–2GB。腐蚀保存频率高，SATA SSD 上每次自动保存都会有肉眼可见的微卡顿，NVMe 基本感觉不到。

**端口要三个，不是一个。** 28015/udp 走游戏数据，28016/tcp 给 RCON，28017 做查询端口；如果要用 Rust+ 手机伴侣，还需要 28082。很多人买完机器发现游戏里搜不到服务器，八成是这三个端口没在防火墙和云平台安全组里同时放行。

还有一个常被忽略的点：**上行带宽**。腐蚀每个玩家平均消耗 200–400KB/s，20 个人同时在线就是 4–8Mbps 的持续上行。国内游戏云常见配置的上行是 10M 或 15M，这意味着 15M 机型在实际运行中大概只能稳定承载 30–50 人，人数再多就得加带宽或换机房。

## 按人数选配置：三档够用了

把上面这些数字翻译成采购决策，大致分三档：

| 场景 | 推荐配置 | 内存 | 端口策略 |
| --- | --- | --- | --- |
| 3–10 人朋友服，原版或少量插件 | 2 核 4G～4 核 8G | 8G 能跑，建议 10G+ | NAT + 端口映射即可，不需要独立 IP |
| 10–50 人社区服，标准插件组 | 4 核 8G～16G | 12–16G | 建议独立公网 IP，方便上服务器列表 |
| 50 人以上，重插件或自定义地图 | 6 核 24G 及以上 | 24–32G | 独立 IP + 大带宽 + 高防 |

最后一档尤其要注意防御。腐蚀服被打的概率不低，尤其是公开拉人的服。国内做抗打的机房不少，雨云的国内游戏云默认带 100G～200G 的 DDoS 防御，这点在选型时比省几十块钱重要。

顺便说一句，如果你搜「Rust服务器租用」其实是想部署 Rust 语言写的后端服务，那选型逻辑完全不同：那种场景看的是编译时的 CPU 和内存峰值，跟游戏服没有共同点，同一批云服务器机型就直接够用，往下看云服务器那一节即可。

## 从买完机器到玩家能连上：实操顺序

拿到服务器之后，腐蚀开服的流程大致是这样：

1. 系统选 Ubuntu 22.04 或 Debian 12，先确认 SSH、时间同步和防火墙状态。
2. 装 SteamCMD，用 `steamcmd +login anonymous +force_install_dir /opt/rust +app_update 258550 validate +quit` 拉服务端。
3. 开放端口：28015/udp、28016/tcp、28017，以及 Rust+ 用的 28082。
4. 写启动脚本，几个关键参数：`-server.tickrate 30`（默认值，调高更吃 CPU）、`-server.saveinterval 300`、`-server.worldsize 3500`（3500 是大多数服务器的最优平衡点）、`-server.seed`（1 到 2147483647 之间，每次 wipe 换）。
5. 首次启动会生成地图，大图等 10–20 分钟很正常，别急着以为卡死了。
6. 本地测试用游戏内 F1 控制台输入 `client.connect 你的IP:28015`。
7. 要装插件就上 Oxide/uMod，上传压缩包后重启服务端。装了插件的服在游戏里显示在"模组"分类，没装的显示在"社区"。

RCON 端口别对全网开放，密码也别设短的。腐蚀的管理口被扫到之后，后果比一个后台弱密码严重得多。

## 几个真正会踩的坑

**公开服需要独立 IP。** 默认开服的游戏服在服务器列表里是找不到的，这属于私服形态。想让服出现在列表、能靠名字搜到，得用独立公网 IP 的机型或加购 IP。

**内存按周期末买，不按开服时买。** 你能承受的人数，取决于 wipe 前一天还剩多少内存，不是开服那天。

**每周四更新是强制的。** Facepunch 每周固定推送补丁，老版本的服务端玩家连不进来。开服工具建议写个更新脚本，别每次手动。

**带宽比 CPU 更容易成为瓶颈。** 国内 15M 上行的机型，人一多就是持续的带宽打满，表现是全员高延迟、物资交互卡顿，很容易被误判成 CPU 不够。

**别用共享超售的机器开公开服。** 腐蚀吃单核，邻居跑满负载的时候你的 tick 就掉，这类问题排查起来非常费时间。KVM 虚拟化、vCPU 有相对确定分配资源的机型更稳。

## 常见问题

**开一个 10 人左右的腐蚀服，最低多少钱？**
选 EPYC 7A23 的 2 核 4G 机型，年付折算下来一个月不到 40 元；如果只是周末玩，用动态计费还要更低。这个配置跑原版、不加大型插件是够的。

**i9-14900K 和 Ryzen 9950X 该选哪个？**
单核性能上 14900K 更强，适合人数多、插件重的公开服；9950X 在全核性能和多开场景更有优势，如果你打算一台机器跑多个服，它更合适。

**NAT 机型能不能做公开服？**
能跑起来，但没法出现在公开服务器列表里，只能靠 IP+端口直连拉人。要做对外拉人的服，独立 IP 几乎是刚需。

**先买一个月还是直接年付？**
先用首月 5 折券买一个月，把真实负载跑一遍，确认内存和带宽够不够。腐蚀的内存需求跟地图大小、建筑密集度关系很大，跑一周之后的数据才有参考价值，这时候再决定是否年付拿 7 折。
